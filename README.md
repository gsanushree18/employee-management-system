# Employee Management System (EMS)

A professional, responsive Full-Stack Employee Management System built with **Node.js**, **Express**, **SQLite**, and **Tailwind CSS**. Designed with a clean Corporate Light Theme UI/UX for seamless organization and employee record management.

## 🚀 Features

- **Admin Authentication**: Secure login system powered by JWT (JSON Web Tokens) and bcrypt password hashing.
- **Employee Directory**: View all employees in a clean, professional corporate table layout.
- **Search & Filter**: Real-time search by employee name and dynamic department filtering.
- **CRUD Operations**: Add, view, and delete employee records (restricted to authenticated admins).
- **Responsive UI**: Modern interface crafted with Tailwind CSS (Corporate Light Theme).
